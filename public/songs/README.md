# Album Songs Ordner
# ==========================================
# Hier kannst du einfach deine Musikdateien (MP3, WAV, M4A, FLAC) ablegen!
#
# Beispiel:
# 1. Lege deine Datei hier ab: /public/songs/01_mein_song.mp3
# 2. Öffne die Datei: /src/config/albumTracks.ts
# 3. Trage dort deinen Song ein mit audioUrl: '/songs/01_mein_song.mp3'
#
# Sobald du die Seite neu lädst, werden deine Songs direkt im Host-Player abgespielt!
